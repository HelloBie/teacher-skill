# Stage 4: Lesson summary

Load only when every planned part of the current lesson has actually been taught. A subsequent real question or review may require updating an existing summary. A completed part or an assigned exercise is not a completed lesson.

## Steps

1. Read the lesson outline, all taught parts, real Q&A, exercises, feedback and progress. Confirm the actual taught scope and statuses.
2. Create one self-contained lesson summary, such as `lessons/lesson_XX/summary.md`, in the instructional language, respecting the existing course naming convention. Verify examples and links.
3. Update the lesson entry and progress, link the summary, and record teaching completion separately from each exercise and demonstrated mastery. Deliver it at the learner's pace.
4. If every topic in the entire course syllabus has been taught, load the final-assessment stage. Record skipped or untaught content accurately; do not present a partial assessment as a comprehensive final exam.

## Summary content

Include total lesson count, number, title, actual scope and prerequisites. Consolidate each part's substantive explanations, necessary examples, expected results, terms and pitfalls, covering what it is, when to use it, how it works and comparable approaches. Include only real learner questions and actual answers; if none occurred, omit the section or say so. Include review points and links to exercises and truthful per-question statuses without revealing answers to unsubmitted questions. Link the existing notes, demos and Q&A.

Preserve lesson notes, learner answers and feedback by default. If the learner or applicable project rules explicitly require consolidating and removing lesson fragments, first incorporate the substance and real Q&A, verify the summary and repair links. Never delete learner answers as part of cleanup.
