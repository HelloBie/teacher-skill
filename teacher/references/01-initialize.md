# 阶段一：课程初始化

适用于新建课程或按用户要求调整课程计划。按用户选择的学科和授课语言填写，不将某一学科的内容或固定课数带入其他课程。下方中文文件名为示例；新课程可按授课语言本地化名称，已有课程沿用现有文件并保持链接一致。用户要求、现有项目规范及已有课程结构优先；以下是新建课程的默认约定。

## 执行步骤

1. 检查用户提供的信息及现有工作区，确认新建还是沿用课程；明确方向、目标、背景和约束，未知时写明合理假设。
2. 确定课程目录，按下方规范创建课程入口、大纲和初始学习记录；适配学科与现有结构。
3. 校验编号、内容和链接后交付大纲。用户只要求规划时暂停于此；用户要求开讲时再加载教学阶段。

## 目录与文件

```text
<课程目录>/
  README.md                     # 课程入口
  docs/
    课程计划.md                 # 学习目标、课纲、教学约定
    学习记录.md                 # 已发生的教学、作答、讲评与下一步
  exams/                       # 结业阶段按需建立，试卷与答卷集中保存
  lessons/
    lesson_01/                  # 每课单独目录，编号与课纲对应
      README.md                 # 本课入口、内容与链接
      lesson_01.md              # 分段讲义，实际授课时创建
      课堂问答.md                # 有真实提问后创建或更新
      课程总结.md                # 本课所有部分讲完后创建
      exercises/                # 本课所有题目、答案和讲评
        EXERCISES.md            # 本课练习入口
        part_01.md              # 题目和答题位置
        ...                     # 按学科需要创建的练习材料
```

- 文件名和编号可适配语言及课程，但同一课必须能定位自己的讲义、练习、问答及总结。新增课次或部分用不冲突的编号；不覆盖或移动学生现有文件。课程入口链接大纲、学习记录和课程目录；每课入口链接本课讲义、练习、真实问答和总结（存在时）。
- 创建时机：初次制定计划建立课程入口、大纲和学习记录；开始具体课时建立该课目录和入口；讲到某部分时保存对应讲义和练习；问答及整课总结按实际发生创建。不要预建空讲义冒充授课。软件实践项目仅在适合学科并经用户要求或有必要时建立。
- 路径仅为默认示例，不强制重命名现有项目、覆盖学生作答或更改其目录约定。练习归该课专属目录；学科不适用时不强制代码、Git 仓库或软件项目。

## `docs/课程计划.md`

新建大纲、学习目标变化或课程顺序调整时创建或更新。使用学习者的语言，包含以下实质内容：

1. **起点与目标**：学习方向、已知经验、目标能力、合理假设和必要前置知识；区分用户明示与待验证的能力。
2. **学习范围与阶段**：主题边界、阶段顺序、各阶段目标和可观察的验收方式；技术或资料选取给出依据，适当核对会变化的事实。
3. **课程安排**：按顺序列出实际总课数、课次编号、标题、核心知识、学习成果、前置关系及课后应用或检验方式。可用表格，避免只有标题没有学习目标。复杂课可标计划中的部分；不要提前标为已讲。
4. **授课与练习约定**：先讲解、示例、跟练，再出题、讲评；知识按“是什么、何时使用、如何使用、类似方案与取舍”讲解；记录学生明确的节奏、语言、练习、批注和整理偏好。
5. **能力验收与结业考试**：按学科列可观察的成果和判断依据，说明所有课程内容讲授完成后依据大纲与已讲内容设计综合试卷；题型、评分和验收方式适应目标。明确计划、出题、讲授、答题和通过是不同状态。用户不要求时不设固定学习周数。

仅要求计划时保存并交付大纲，不自动开课；学习方向虽已明确但目标细节未知时，注明合理假设并允许调整。大纲变更应同步总课数及相关链接，不擅自删除实际教学历史。

## `docs/学习记录.md`

创建课程时初始化；每次授课、学生提问、提交或讲评后根据实际情况更新。建议内容：

- **当前状态**：课程名称、总课数、当前课次与部分、当前阶段、上次已讲内容、下一步，以及大纲和当前课链接。
- **学习者情况与偏好**：已知经验、目标、授课语言（与所学语言不同则分别记录）、语言支持、节奏和用户明确的特殊要求；未知内容写未知，不虚构。
- **课次/模块进度表**：课次或模块、实际教学状态、练习或验收状态、证据/链接。分别记录已计划、讲授中、已讲授和练习未提交、待讲评、部分通过、需修正、已通过等；某些状态不适用时省略，不能把出题或模板可运行视为通过。
- **本课逐题结果**：题号、已提交或未提交、每轮结论及题目/批注链接；判断有缺陷的题目标注题意待澄清而非擅自判错。
- **结业考核状态**：未开始 / 命题中 / 已发卷待作答 / 已提交待讲评 / 已讲评未通过或待完善 / 已通过，按事实及试卷、答卷、讲评文件链接记录；尚未具备考试条件时不标通过。
- **问答及重点**：链接真实课堂问答、已交付的课程总结和实际练习，不编造问题或反馈。可附易混点及历史记录，但不要求学习者反复补做其明确不想补充的旧题，也不因此记为通过。

授课完成、整课内容完整、已交练习及能力验收分开表述。恢复教学时先读取学习记录并核对相关真实文件；学生明确说跳过、回退或暂停时立即更新下一步。

## 校验

检查课程入口、大纲、进度和已创建的课次链接相互可达，课次编号、总数与实际课纲一致，状态与真实材料一致。无需创建当前阶段不需要的文件。不得将学习记录中的占位符视为实际学生回答。
