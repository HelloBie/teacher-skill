# 阶段四：整课课后总结

仅在当前整课所有计划部分实际讲授完毕时加载；学生有新问题或新讲评时可更新已有总结。

## 执行步骤

1. 读取本课大纲、全部已讲部分、真实课堂问答、练习/讲评和学习记录，确认讲授范围及实际状态。
2. 按下方规范编写自成体系的单文件总结，保留讲义核心内容与真实问答；检查例子和所有链接。
3. 更新本课入口及学习记录，链接总结，注明整课授课、每题状态和下一步；讲完不自动记为验收通过。
4. 按用户节奏交付总结；已讲完的内容和学生记录继续保留，除非适用规则或用户明确要求整理。
5. 如果整个课程大纲的全部内容均已讲授完成，加载结业考试阶段并按大纲准备考核；若有跳过或未讲内容，准确记录尚未覆盖的范围，不称为全课程结业考试。

## `lessons/lesson_XX/课程总结.md`

只有本课**所有计划部分**已实际讲授后才创建；分段授课或建好练习不等于整课讲完。总结是自成体系的单个文件，默认包含：

1. 总课数、当前课次/编号/标题、实际讲授范围和必要前置知识。
2. 各部分核心内容：是什么、何时使用、如何使用、类似方法与取舍；保留必要步骤、实例、预期结果、术语和易错点。不能只列链接代替内容。
3. 真实课堂问答：记录实际问题与回答要点和必要上下文；没有真实问题时注明无或不设该节。
4. 复习要点和已讲评的易混点；练习入口、逐题状态及讲评位置。未作答题不公布解析；授课完成与练习完成、能力通过分别标明。
5. 实际仍存在的讲义、演示、问答和练习链接。默认保留原始资料与学生作答；用户或适用项目规则明确要求删除分段讲义时，先完整纳入内容、核对和更新链接，再按约定清理，绝不清理学生作答。

总结的标题和正文遵循课程授课语言，文件名可按既有课程约定或该语言本地化。验证总结中的例子和本地链接，并在该课 README、学习记录中链接总结。若之后出现新的真实问题或讲评，补充相应内容和状态，不改写历史为已提前完成。
