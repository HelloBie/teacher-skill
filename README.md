# Teacher

中文 | [English](README.en.md)

[![skills.sh](https://skills.sh/b/HelloBie/teacher-skill)](https://skills.sh/HelloBie/teacher-skill/teacher)

**把学习目标变成可持续推进的课程。**

Teacher 是一个通用教学技能，适用于支持 `SKILL.md` 格式的 AI 编程助手。你只需说明想学什么，Teacher 就能根据目标和已有经验制定课程大纲，按照「讲解 → 示例 → 跟练 → 练习 → 讲评」开展教学，并把讲义、作答和进度保存在工作区，方便下次接着学。

它不限于编程：语言、设计、数学、写作、产品、职业技能等方向，都可以根据学科特点选择合适的讲解和练习方式。

> 项目提供的是供 AI 助手读取的技能指令和文件规范，不是独立的教学应用，也不包含预先编好的完整课程。实际教学效果取决于所用助手、模型、工具和课程内容。

## 特性

- **多语言授课**：按用户指定的授课语言生成讲解、材料与反馈；未指定时沿用用户当前使用的语言。
- **按目标规划**：结合学习方向、已有经验和目标能力设计课程大纲，记录前置知识和阶段成果。
- **先教再练**：针对重要知识讲清是什么、何时使用、如何使用以及类似方案的取舍，再安排跟练和独立练习。
- **持续记录**：维护课程计划、课次状态、逐题反馈和下一步，区分已讲授、已答题和已通过。
- **尊重原作答**：检查时保留学习者的答案与代码，在下方追加逐题批注；未作答和题意不明确的情况如实记录。
- **整课归纳**：每课全部部分讲完后，将讲义、真实课堂问答和复习要点汇总成一个文件。
- **结业自测**：整门课程讲完后，根据实际大纲和授课内容设计综合考核，并在提交后给出有依据的讲评。
- **按阶段加载**：只在进入初始化、授课、讲评、总结或结业考试阶段时读取对应的详细规范。

## 安装

### 使用 Skills CLI 安装

需要 Node.js 和 npm。运行：

```bash
npx skills add HelloBie/teacher-skill --skill teacher
```

根据提示选择要安装的助手；默认安装到当前项目。如需安装到全局，可添加 `-g`，请先检查是否已有同名技能。技能页面：[Skills.sh 上的 Teacher](https://skills.sh/HelloBie/teacher-skill/teacher)。

### 手动安装到 Codex

将仓库中的 `teacher` 文件夹复制到 Codex 的技能目录。以下命令使用 `$CODEX_HOME`；如果没有设置，则使用 `~/.codex`。

```bash
git clone https://github.com/HelloBie/teacher-skill.git
cd teacher-skill

SKILLS_DIR="${CODEX_HOME:-$HOME/.codex}/skills"
mkdir -p "$SKILLS_DIR"

# 仅在目标不存在时复制，避免覆盖已有的 teacher 技能。
if [ ! -e "$SKILLS_DIR/teacher" ]; then
  cp -R teacher "$SKILLS_DIR/teacher"
else
  printf '%s\n' "已存在 $SKILLS_DIR/teacher，请先检查已有技能。"
fi
```

安装后启动一个新的 Codex 会话，然后通过 `$teacher` 调用。已有会话是否立即识别新技能取决于客户端的技能加载时机。

### 其他支持 `SKILL.md` 的助手

将本仓库的 `teacher/` 文件夹完整放入目标助手的技能目录，保留 `references/` 子目录，再按照该助手的方式启用技能。不同产品对技能发现、工具权限和文件访问的支持可能不同，请参考对应产品文档。

## 快速开始

在一个适合保存学习材料的工作区中，向支持该技能的助手发送：

```text
$teacher 我想系统学习数据分析。我会基础 Excel，希望能够独立完成一份分析报告。
请先为我设计课程大纲和练习方式。
```

只要求大纲时，Teacher 会先制定计划；你可以确认方向或提出修改，再说「开始第一课」。也可以直接请求开始学习：

```text
$teacher 我想从零系统学习摄影，请设计课程并开始第一课。
```

也可以明确指定授课语言，例如“用英文讲解这个课程”，或“用中文教我英语”。授课语言与所学语言可以不同。

课程进行中可以自然交流：

```text
继续学习
这部分我没理解，请换个例子解释
练习做完了，请检查
暂停课程
```

继续课程时，Teacher 会先读取已有计划和进度，从当前课未讲的部分接着讲。学习者可以随时调整顺序或节奏；先前未补充的练习不会自动算作通过。

## 教学流程

| 阶段 | Teacher 的工作 | 主要产物 |
| --- | --- | --- |
| 课程初始化 | 根据目标、背景和约束设计大纲，建立课程与进度记录 | 课程计划、学习记录 |
| 教学与练习 | 报课次，讲解知识、示范并带领跟练；为已讲内容出题 | 分段讲义、练习入口、答题文件 |
| 练习讲评 | 核对实际作答，保留原文，追加带轮次和日期的反馈 | 逐题批注、更新后的进度 |
| 整课总结 | 本课所有部分讲完后汇总内容和真实课堂问答 | 本课课程总结 |
| 结业考试 | 全部课纲内容讲完后，依据实际授课内容设计综合自测 | 试卷、答题文件、讲评 |

每个阶段的详细步骤和文件要求放在独立的参考文件中。授课、练习完成和能力验收分别记录：创建计划、发出题目或运行模板都不等于掌握或通过。

## 课程材料如何组织？

新建课程时，默认按下面的结构保存；如果工作区已有课程约定，Teacher 会优先适配现有结构。非编程学科不需要代码文件或 Git 仓库。

```text
<课程目录>/
├── README.md
├── docs/
│   ├── 课程计划.md
│   └── 学习记录.md
├── lessons/
│   └── lesson_01/
│       ├── README.md
│       ├── lesson_01.md
│       ├── 课堂问答.md          # 有真实课堂提问时
│       ├── 课程总结.md          # 本课所有部分讲完后
│       └── exercises/
│           ├── EXERCISES.md
│           └── part_01.md
└── exams/                       # 整门课程讲完后按需建立
    ├── README.md
    └── exam_01.md
```

上述文件根据教学进度逐步创建，不会在建课时把所有讲义和答案预先填好。结业考试用于自测，不能替代官方资格认证。

## 技能结构

```text
teacher/
├── SKILL.md                     # 技能入口、阶段路由和通用约定
└── references/
    ├── 01-initialize.md         # 课程初始化
    ├── 02-teach.md              # 教学与课后练习
    ├── 03-review.md             # 练习讲评
    ├── 04-conclude.md           # 整课总结
    ├── 05-final-exam.md         # 结业考试
    └── en/                      # 各阶段的英文规范
```

修改技能时，请保持 `SKILL.md` 中的阶段链接与实际文件一致；参考文件中的默认路径应允许适配已有课程，避免覆盖学习者的作答或已有材料。

## 适用边界

- Teacher 负责组织学习过程；涉及易变化或高风险内容时，仍需根据主题核对权威资料。
- 学习记录保存在助手可访问的工作区。请自行决定哪些课程材料适合提交或公开，避免把个人答案和敏感信息意外上传。
- 安装此技能不会自动创建 GitHub 仓库、发布内容或代表用户发送消息；相关操作需由用户授权。
